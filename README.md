## Overview

This repository contains the artifacts and enhancements developed for CS-499: Computer Science Capstone at Southern New Hampshire University. The capstone demonstrates growth in three computer science disciplines: 

- Software engineering and design
- Algorithms and data structures
- Databases

## Capstone Projects

### 1. Software Engineering and Design: Impetus

**Technologies:** Java, Android SDK, SQLite

Impetus is an Android application designed to track personal weight and progress over time.

The planned enhancement focuses on application architecture, authentication security, input validation, and automated testing.

**Location:** `capstone-projects/software-engineering/impetus/`

### 2. Algorithms and Data Structures: Course Planner

**Technologies:** C++, Binary Search Tree, CSV

Originally developed for CS-300, this application manages course information and prerequisites.

The planned enhancement focuses on graph-based prerequisite analysis, cycle detection, and topological sorting.

**Location:** `capstone-projects/algorithms/course-planner/`

### 3. Databases: Animal Shelter Dashboard

**Technologies:** Python, MongoDB, Jupyter Notebook, Dash

Originally developed for CS-340, this application provides database operations and an interactive dashboard for animal shelter records.

The planned enhancement focuses on database query design, validation, indexing, and performance.

**Location:** `capstone-projects/databases/animal-shelter/`
